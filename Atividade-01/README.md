**Atividade — Classes e Objetos**

- Criar a classe Aluno com seu nome, idade, matrícula, peso, altura. Coloque as condições para dizer que você é maior de idade.
- Criar um construtor.
- Criar o método exibirInformacoes().
- Criar a classe Main para instanciar dois alunos.
- Exibir as informações no terminal. Entrega: criar um fork, adicionar os arquivos Java em uma pasta identificada pelo aluno e abrir um Pull Request.

**IMPORTANTE!!!**

- Professor publica o exercício
- Aluno resolve no VS Code
- Aluno cria um Fork e envia um Pull Request
- Professor recebe, comenta e corrige

**Observação:
Entre na própria conta do GitHub e acesse:
Repositório ATIVIDADES — POO Java 2026.2**

- Clicar em Fork, no canto superior direito.
- Clicar em Create a new fork.
- Em Owner, selecionar a própria conta.
- Manter o nome ATIVIDADES.
- Clicar em Create fork.
  
**Isso criará uma cópia do seu repositório na sua conta.**

Dentro do fork, você deverá:
- Abrir a pasta Atividade-01.
- Clicar em Add file → Upload files.
- Enviar os arquivos Aluno.java e Main.java, preferencialmente organizados em uma pasta com seu identificador, como Entregas/Marcia/.
- Clicar em Commit changes.

O aluno entrega ao professor
- No fork, clicar em Contribute → Open pull request.
- Conferir se o destino é POO-java-2026-2/ATIVIDADES, na branch main.
- Informar o nome e a atividade no título.
- Clicar em Create pull request.
